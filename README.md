# lkrekcode.github.io

Personal GitHub Pages site for Lewis Kreku (lkrekcode). This repository contains a static website (HTML/CSS/JS) — including a terminal-style emulator component — used to publish a portfolio / demo site via GitHub Pages.

Repository: [Cyy-ther/lkrekcode.github.io](https://github.com/Cyy-ther/lkrekcode.github.io)

## Features
- Static GitHub Pages site (HTML, CSS, JavaScript)
- Terminal emulator UI component for interactive demos
- Responsive layout and styles optimized for a portfolio/demo
- Easy to preview locally and deploy via GitHub Pages
